Ahmed Sorour portfolio, new design
==================================

Files
  index.html   page (keeps your meta tags, favicon and Google Analytics ID)
  Ahmed_Sorour_CV.pdf   your one-page CV; the CV button on the site opens this file
  style.css    all styling
  script.js    theme, menu, typing roles, active nav, analytics events

How to use
  1. Upload index.html, style.css, script.js and Ahmed_Sorour_CV.pdf to the root of your repo,
     replacing the old files (same folder as index.html).
  2. Copy the two files in images/ (portrait.jpg and avatar.jpg, resized from your photo) into your images folder.
     Keep images/best.png as the favicon.
  3. Commit and push. GitHub Pages will publish it.

Things to edit
  - Project links: all three point to https://github.com/Ahmed-Soro. Replace each
    with the repo URL of that project.
  - Project screenshots: save a screenshot of each project's real work (a chart, a notebook output)
    with these exact names and the page shows it instead of the sample code window:
      images/projects/employee-productivity.png
      images/projects/exploratory-data-analysis.png
      images/projects/predictive-machine-learning.png
